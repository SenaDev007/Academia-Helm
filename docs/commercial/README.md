## Contenu

Le dossier comprend 7 parties :

1. **Synthèse exécutive** — positionnement global + 4 KPIs visuels
2. **Partie 1 — Inventaire des 21 modules** — tableau récap + 6 modules cœur détaillés + 7 modules complémentaires + Platform/AI Agents + 7 modules transverses
3. **Partie 2 — 17 problèmes & solutions** — format side-by-side rouge/vert (EducMaster, reçus papier, communication, bulletins, présences, paie, vue multi-niveaux, offline, admissions, contrats, recouvrement, conformité fiscale, bulletins maternelle/primaire, fiches pédagogiques, semainier, registre notes, exports EducMaster par classe)
4. **Partie 3 — Nouveau pricing 2026** — tableau récap (300k activation + 50k-150k/an selon tranche) + 4 fiches plans détaillées + ce qui est inclus (Web+Desktop+Mobile) + options bilingue + SMS/Email
5. **Partie 4 — Comparaison concurrentielle vs Logico** — tableau 27 critères + 5 avantages stratégiques
6. **Partie 5 — Analyse de rentabilité** — coûts infra (630k FCFA/an) + point mort (2 écoles en Année 1) + scénario 12 mois + projections Années 2-3 + analyse de sensibilité
7. **Conclusion** — 6 avantages du nouveau modèle + positionnement + 5 étapes de démarrage + contact
