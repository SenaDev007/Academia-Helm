Guide de saisie pour le dashboard Gupshup — 20 templates à créer
Généré le 02/07/2026 à 17:08 · Langue: Français · Catégorie: UTILITY · Personnalisation: Nom école en body (position 1)

⚠️ VERSION 2.0 - Changement important

Cette version supprime le header paramétré qui causait le rejet Meta Variables can't be at the start or end of the template.

Le nom de l'école est maintenant intégré dans le body en première ligne : Etablissement : {{1}}

Ne configurez PAS de header dans le dashboard Gupshup pour ces templates.

📝 Procédure pour chaque template

  1. Aller sur https://portal.gupshup.io → Dashboard → WhatsApp → Votre App → Templates → Create Template
  2. Selectionner Category = UTILITY et Message Type = Custom Message
  3. Renseigner les champs depuis la carte du template ci-dessous (cliquer sur chaque valeur pour copier)
  4. Header: NE PAS configurer de header (laisser vide)
  5. Body: Coller le bloc "Body" (les variables {{1}}, {{2}}... sont déjà placées)
  6. Footer: Coller le footer statique
  7. Sample Body: Coller le bloc "Sample Body (format TEXTE COMPLET)" — c'est le body avec les valeurs d'exemple substituées
  8. Cliquer Preview and Submit
  9. Répéter pour chaque template — Meta valide en 24-48h
