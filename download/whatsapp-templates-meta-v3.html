Academia Helm — 20 Templates WhatsApp Meta v3 (avec 3 boutons URL)

Format conforme aux regles Meta : variables {{snake_case}}, header + footer courts, 3 boutons URL dynamiques (site web, WhatsApp, appel).

Regles Meta respectees dans tous les templates ci-dessous

  • Variables au format {{minuscules_avec_underscores}} — jamais {{1}}
  • Aucune variable au debut ou a la fin du body (texte fixe obligatoire)
  • Aucune variable en debut/fin de ligne (toujours entouree de texte)
  • Noms de templates en minuscules avec underscores (max 512 caracteres)
  • Categorie : UTILITY (utilitaire) — Langue : Francais (fr)
  • Header TEXT court (≤ 60 caracteres) — Footer TEXT court (≤ 60 caracteres)
  • 3 boutons URL par template (Meta permet jusqu'a 10 boutons par template)

Boutons URL (3 par template)

  • Bouton 1 — "Consulter le site" : URL https://{{1}}.academiahelm.com → variable subdomain (ex: "cspeb" → ouvre https://cspeb.academiahelm.com)
  • Bouton 2 — "Discuter sur WhatsApp" : URL https://wa.me/{{1}} → variable whatsapp_number (ex: "22997123456" — format E.164 sans +)
  • Bouton 3 — "Appeler l'ecole" : URL https://wa.me/{{1}} → variable phone_number (ex: "22997123456" — format E.164 sans +)

Note importante : Meta n'autorise pas de variables dans les boutons PHONE_NUMBER (numero fixe uniquement). Pour avoir un bouton d'appel dynamique par ecole, on utilise un bouton URL avec wa.me/ qui ouvre WhatsApp, puis l'utilisateur peut cliquer sur l'icone appel pour appeler le numero.
